# 最终 PRISM / Empirical 抽样分布诊断

分析时间：2026-11-15。对象为已完成的 olmo1b-small-v1、n=1024、seeds 11/23。
这是对既有分布和 queries 的只读分析，不修改采样、训练或评价产物。

## 来源与复核

正式 design.npz 的 SHA256 与 Design 独立验收 receipt 一致：
`8f34e698862bfb3658bc74ddb8da05d8c6db07ed6d983d92711e8ea8cf486a2e`。
仅传回 empirical/prism/index 三个 NPY 成员和四组 queries/receipts，
三个成员的本机与集群 SHA256 一致。数值分析在本机执行，没有申请新 GPU 或调用 API。

验证两分布均非负、归一化、18000 条边与 3000×6 的索引一致；
验证每组 queries 哈希，按原 seed 和原 NumPy 有放回抽样逐项重放，
四组全部 4096 个 draw_id、edge_id、prompt_index、a/b 与保存概率完全一致。

## 分布本身：差异很大

Empirical 在 3000 个 prompt 上均匀，并在每题 6 条无序比较边上均匀，
因此每边概率 1/18000。PRISM 使用通过原全局 gap 验收的最优设计分布。

| 指标 | Empirical | PRISM |
| --- | ---: | ---: |
| 正概率比较边数 | 18000 | 6021 |
| 前 180 条边（全部边的 1%）的概率质量 | 1.00% | 88.3297% |
| 前 900 条边（5%）的概率质量 | 5.00% | 96.3108% |
| 承载 90% 概率所需边数 | 16200 | 202 |
| 最大单边概率 | 0.005556% | 0.982362% |
| 逆集中度 1/sum(q²) | 18000 | 170.505 |
| 正概率 prompt 数 | 3000 | 2099 |
| 前 150 个 prompt（5%）的概率质量 | 5.00% | 87.6980% |
| 承载 90% 概率所需 prompt 数 | 2700 | 166 |

边分布总变差距离为 0.931661，prompt 边缘分布总变差为 0.868491。
总变差为 0 表示分布相同，接近 1 表示概率质量差异很大。
逆集中度只是概率集中程度，不是独立标签数量、特征秩或有效参数维度。
6021 条边有正概率不代表权重接近均匀，其中大量边只承载很小质量。

## 实际 1024 次抽样

| 方法 | seed | 不同比较边 | 不同 prompt | 首次出现之外的重复边抽样 | 同一条边最多抽取次数 |
| --- | --- | ---: | ---: | ---: | ---: |
| Empirical | 11 | 993 | 865 | 31 | 2 |
| Empirical | 23 | 997 | 864 | 27 | 2 |
| PRISM | 11 | 266 | 242 | 758 | 17 |
| PRISM | 23 | 269 | 243 | 755 | 18 |

在 n 次有放回抽样中，不同边数的期望为 sum_e[1-(1-q_e)^n]。
n=1024 时，Empirical 期望 995.44 条，PRISM 期望 270.45 条，
实际覆盖与分布对应的预期一致，没有出现抽样器没有按 q 执行的迹象。

同 seed 跨方法，不同比较边集合的交集分别只有 14 / 12 条，
prompt 集合交集为 63 / 64 个。最终标签预算仍是每组 1024，
不是把 PRISM 的重复比较只算成 266/269 个有效标签。

## 对结果的含义

1. 两种方法确实形成了明显不同的数据设计；本轮结果不能用“分布几乎没变”解释。
2. PRISM 在有限预算下非常集中，约 74% 的抽样是已出现比较边的再次抽取，
   实际 prompt 覆盖约为 Empirical 的 28%。重复设计点符合既定 i.i.d.
   有放回机制，每次需要对应的新判断；它们不自动等于无效或浪费的标签。
3. 这种集中可能帮助重要特征方向的估计，也可能牺牲有限样本下的偏好覆盖，
   或放大代理几何与真实偏好的不匹配。当前统计本身不能证明哪种效应占主导，
   不能直接认定集中导致胜率表现。
4. 因此后续诊断应同时关注 PPO 的优化有效性，以及集中采样后的 Reward 泛化。
   此前将 PPO 强度列为首要线索不应扩展成排除了采样/Reward统计效果。

这不推翻已通过的 Design 数值证书或 BT 数值收敛，也不证明代理统计设计
必然提高下游策略质量。下一步可先利用已有产物检查不同 prompt/比较边上的
Reward 泛化和 Judge 一致性；均匀混合、概率下限、去重采样或改 ridge 都会
改变研究设定，不能直接据此回头修改本轮冻结实验。

本机完整统计及图位于忽略目录 local/sampling-analysis；最终胜率、KL 与
IFEval 未改，见 final-experiment-report.md。
