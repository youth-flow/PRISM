# PRISM 六阶段实验总结（2026-11-15）

本轮 Empirical/PRISM、1024 标签预算、seeds 11/23 的四单元实验已全部完成。
最终独立验收 1979130 通过，未留下等待中的训练或评价任务。
结果是混合的：PRISM 的 IFEval 和 KL 点估计较好，Empirical 的 Luna 胜率较高；
本轮没有证明 PRISM 在总体偏好上优于 Empirical。

## 问题、改动与额外开销

### Design：b/K 正确，原数值算法未在预算内收敛

原问题始终是：

`min F(q) = trace(K A(q)^-1)`，
`A(q) = 0.01 I + sum_e q_e v_e v_e^T`，`q >= 0`、`sum(q) = 1`。

3000 个 prompt、每个 4 候选形成 18000 条无序比较边；使用完整 2048 维，
没有 PCA、概率下限或新的研究正则。Empirical 均匀选 prompt 后均匀选边，
PRISM 使用 Design 得到的边分布。b 拟合只中心化 logp 目标，不中心化特征；
K 是 prompt 内代理概率加权协方差的均值。

原 away-step FW 的稠密初始分布导致逐边去质量很慢。1978113 用 26:28、
500 步后 F=1.137937、G=1.060549，未达标。改用冗余初始混合原子的 FW
变体后，1978299 用 26:09、500 步后 F=1.126483、G=0.981054，仍未达标。
两次都保留失败记录；抽样闸门阻止继续调用训练 API。

独立复核 1978385 得到 b 正规方程相对残差约 3.48e-14，K 与独立 pairwise
公式相对误差约 4.15e-16，说明不能把这次问题归咎于 b/K 没算对。

获得用户授权后，改用非负权重 `q=w/sum(w)` 的联合 L-BFGS-B，复用原几何
及旧数值起点。**搜索方向和求解算法确实改变了，数学目标与可行域没有改变。**
权重参数化包含零坐标，不剔除原来可行的边。最终不以优化器 success 判定通过，
仍用原 q 空间全局 FW gap `G=q^T g-min(g)` 验收。

正式 1978547 用 7:11、214 次联合迭代达到 F=0.89300504565；独立 1978548
用分块 A 和 LU 重新计算全部边，得到 G/F=9.11865834e-5，低于原 1e-4。
每次求解上限仍为 500；不能把之前两次各 500 步和试算成本隐去，宣称累计仅
计算 214 步。求解证书证明原设计目标的数值近优性，不保证后续 PPO 胜率提升。

真实核函数基准发现 16 线程约 2.94 秒、32 线程约 4.36 秒，因此后续采用
16 CPU。增加核心不一定提高这类矩阵计算的吞吐。

### Judge：比较任务和原题选项混淆，随后有格式和网络失败

初版 A/B Judge 有时回答原题的 C/D，而不是选择两个候选回答。
增加任务边界的 v2 通过小样本后，完整批次仍失败；v3 原生 JSON 真实回归
28 例中仅 27 例最终通过，也没有放行完整训练。

最终采用统一 v4 原生严格工具字段，候选 ID 为 response_A/response_B。
这里的工具调用只是结构化偏好输出，不执行外部工具。其有效请求路径改为官方
beta Chat Completions；**输入封装、输出协议和有效接口路径有真实改动，不能
说 API 实现完全未变。** 原模型、偏好准则、温度、thinking、输出 cap、queries
与标签预算保持不变，四个训练单元统一使用同一最终协议与解码规则。

v4 原生工具字段的 A/B 简写允许无损映射；C/D、错误工具、重复/多余键、截断
仍拒绝。只选择原始流中最早可解释的有效回答，不根据实验结果选择标签。
对最后语义槽位无网络返回的情况，显式启用最多两次同 payload/seed/flip 的
网络重传；原三次语义尝试不增加，格式失败不获得额外语义槽位。

旧 v1/v2 批次按原字节和哈希归档，最终没有混入其标签。复核后复用 v4 中
2841 个有效观察，只补齐 1255 个缺失观察，最终 4096 有效标签对应 4420 次
记录的 HTTP 尝试。被忽略、失败和诊断调用也纳入费用统计。

四个 Reward 仍是均值 BT loss 加固定 L2=0.01，没有加入 importance weighting
或辅助目标。独立梯度无穷范数均低于 1e-6，强凸目标差上界均小于 4.1e-9。

## 结果与可支持的结论

Luna 平局计半分，每个 prompt 先平均 AB/BA，再做标准误与 2000 次 bootstrap。
不能把两种展示顺序当成两个独立 prompt。两训练 seed 的变异另行报告。

| 方法/seed | Luna 对 SFT 胜率 | IFEval prompt strict | 序列 KL MC 均值 |
| --- | ---: | ---: | ---: |
| 共享 SFT | 基准 | 46.9501% | 0 |
| Empirical 11 | 51.70% | 46.3956% | 0.002366 |
| Empirical 23 | 53.20% | 44.9168% | 0.019454 |
| PRISM 11 | 50.15% | 46.9501% | 0.009678 |
| PRISM 23 | 50.70% | 47.8743% | -0.002606 |
| Empirical 两 seed 均值 | **52.45%** | **45.6562%** | **0.010910** |
| PRISM 两 seed 均值 | **50.425%** | **47.4122%** | **0.003536** |

PRISM 直接对 Empirical：seed11 胜率 48.70%，95% 区间 46.05%–51.80%；
seed23 胜率 47.65%，区间 44.70%–50.45%。两 seed 算术均值 48.175%，
两个区间均包含 50%。四组对 SFT 的胜率区间也均包含 50%。

由此能够支持的判断是：

1. **这轮没有建立 PRISM 的偏好胜率优势。** Empirical 对 SFT 的点估计高
   2.025 个百分点；PRISM 直接比较点估计低于 50%，但不足以据此认定显著较差。
2. **PRISM 的指令遵循表现较好，但差距需要保守解释。** IFEval 比 Empirical
   高 1.7560 个百分点，比 SFT 高 0.4621 个百分点；后者仅相当于每个 seed
   平均多通过 2.5/541 个 prompt。这是点估计，尚无配对显著性结论。
3. **两种策略的 KL MC 均值都很小，尚不能证明 PRISM 的真实 KL 更低。**
   每组标准误约 0.019–0.022，大于大部分均值。有限采样的 log-ratio 均值
   可以为负，PRISM23 的负值保留；这不意味着理论 KL 为负。另行加载 reference
   的独立复算最大误差 3.6622e-4，低于预定 0.002 容差。
4. **数值求解成功与科学假设成立是不同结论。** Design 原目标近优、BT 拟合
   与 PPO 执行通过验收，说明实现链路闭合；不能由此推出代理几何一定预测
   强 Judge 的偏好收益。这轮限于单模型、单预算、两个训练 seed。

可能需要解释的现象包括代理几何和真实偏好的差异、Reward 分数尺度与固定
PPO KL 系数的相互作用、评价噪声。它们目前是待检验解释，不是已确认的错误。
一般评价回答约 233–238 tokens，512 cap 截断率约 24%–25%，SFT 为 25.6%；
因此结果也应明确限定于这次冻结的长度协议，不能看完结果后只调整某个方法。

## 下一步建议

2026-11-15 的只读分布诊断补充：PRISM 前 1% 比较边承载 88.33% 概率，
实际每组 1024 标签仅覆盖 266/269 条不同边、242/243 个 prompt；
Empirical 分别覆盖 993/997 条边、865/864 个 prompt。四组原 seed 抽样重放
完全一致。后续应同时检查 PPO 优化有效性与集中采样后的 Reward 泛化，
不能把原因仅归于 PPO 强度。完整口径见 [抽样分布诊断](sampling-distribution-analysis.md)。

进一步使用原标签做不新增调用的事后交叉留出诊断：排除两方法Reward训练
出现过的全部prompt后，四个Reward对另一seed已有标签的准确率约55%–60%，
BT logloss约1.21–1.24。PRISM与Empirical评价回答约39%–40%逐字相同，
这些全部被Luna判平。诊断边界、分数范围与Judge一致性见
[Reward/PPO/Judge诊断](reward-ppo-judge-diagnostics.md)，不改写本轮主要指标。

进一步的[校准与有效性复核](diagnostic-validation-2026-11-15.md)已完成80次
独立记录的参考判断（$0.204478）和单卡57秒既有回答打分；四组自身Reward
变化均未检出稳定正收益，建议先做小规模PPO有效更新验证，再决定增强训练。
