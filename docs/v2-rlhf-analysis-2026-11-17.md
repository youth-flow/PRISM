# V2 的 RLHF 分析（2026-11-17）

本报告分析已验收的 V2 两档八单元。没有新增标注、GPU 训练、推理请求或改写正式指标。额外统计仅读取已有 query、训练日志与评价 packet，属于事后描述性诊断，不替代预先冻结的主分析。[正式结果与审计](v2-results-2026-11-17.md)。

我的判断是：本次完成了经过独立验收的实验，但尚未显示 PRISM 优于 Empirical；两方法相对 SFT 的 RLHF 增益也弱。下一步最有价值的是识别“设计几何→Reward 泛化→策略优化”的哪一环没有把信息优势传递下去。

## 主结果应如何理解

| 预算 | 方法 | 对 SFT 胜率（两 seed 均值） | IFEval strict | 序列 KL MC |
|---|---|---:|---:|---:|
| 2048 | Empirical | 50.00% | 46.30% | 0.052744 |
| 2048 | PRISM | 49.20% | 45.93% | 0.046990 |
| 4096 | Empirical | 51.05% | 45.93% | 0.065964 |
| 4096 | PRISM | 51.30% | 46.58% | 0.061295 |

SFT IFEval 为 45.47%。4096 档 PRISM IFEval 较 SFT 高约 1.11 个百分点，较 Empirical 高约 0.65 个百分点，属于描述性小差异，没有在本轮做证明该差异显著的配对检验。

直接 PRISM 对 Empirical：2048 的两个 seed 为 49.50%/49.20%；4096 为 49.95%/49.00%。四个区间都包含 50%，且四个点估计均未超过 50%。不能用 PRISM 对 SFT 的 51.30% 高于 Empirical 的 51.05%，转而宣称 PRISM 赢了直接比较。

也不能把“未显著”解释为严格等效。500 prompts 与两个训练 seed 限制小收益的识别；AB/BA 不是两倍独立样本。PRISM 从 2048 到 4096 的对 SFT 均值增加 2.10 个百分点，其中 seed11 仅增加 0.15、seed23 增加 4.05，尚无跨 seed 稳定的预算收益结论。

## 新核对：PRISM 有放回采样非常集中

下面直接核对 V2 的 query 前缀，不引用 V1 的覆盖数字。四份原 4096 queries 与其 receipt 的 SHA256 一致；2048 取相同观察流严格前缀。

| 预算 | 方法 | 不同比较对（两 seed 范围） | 不同 prompt | 首次出现以外的重复抽取比例 |
|---|---|---:|---:|---:|
| 2048 | Empirical | 1918–1928 | 1469–1484 | 5.9%–6.3% |
| 2048 | PRISM | 351–363 | 308–321 | 82.3%–82.9% |
| 4096 | Empirical | 3638–3654 | 2241–2253 | 10.8%–11.2% |
| 4096 | PRISM | 510–512 | 437–443 | 87.50%–87.55% |

PRISM4096 同一条边最多抽到 60/64 次。每次原抽取均有自己的判断，不能将重复边简单称为无效标签；重复观察可以提高同一方向的统计精度，但不提供新的比较方向。PRISM 从 2048 增到 4096，两个 seed 的新增不同比较对仅 149/159 条；Empirical 为 1736/1710 条。

因此，“预算翻倍”在两个方法中所增加的覆盖很不一样。对于本轮 2048 维固定线性表示，PRISM4096 经验比较协方差的秩至多是 510–512；实际有效子空间 H 或 K 可能更低维，所以这一上界不能证明设计错误。但它使“是否覆盖真正影响策略的重要方向”成为应优先检查的问题。ridge 保证数值可逆，不等于数据覆盖已满足理论条件。

集中采样可能正是最优设计要做的事情；当前数据没有证明集中导致收益弱。需要将它与代理几何失配、标签噪声、Reward 偏差及实际策略响应一起检验。

## PRISM 理论与当前实现之间的关键距离

你给出的理论中，局部 prospective regret 是

$$R_{\mathrm{Pro}}=\frac{1}{2\beta}(\widehat w-w^*)^\top K(\widehat w-w^*),\qquad K=G^\top F^\dagger G.$$

其设计准则关注影响下游局部决策的 Reward 误差。当前代码的 K 是用四候选、SFT 序列 logp 拟合的 loglinear 代理概率下的特征协方差，不是显式计算实际 LoRA 策略的 score/Fisher 后得到的同一个 K。最终 gap 9.801458e-5 证明给定代理目标的数值近优，不能证明代理 K 与实际策略决策几何接近。

若代理特别强调的方向不能被当前 actor LoRA 有效利用，或者没有对应真实偏好差异，降低该代理准则未必带来最终胜率改善。这是对本轮现象的合理解释候选，尚无因果对照。

理论还使用正确设定的线性 BT、条件独立标注、覆盖及局部最优响应等假设；本轮使用 L2 惩罚估计与有限步 PPO。它是受理论启发的现实实验，不能把实际 PPO 胜率等同于局部代理 regret，也不能据本轮未胜出否定理论命题。

## PPO 真更新了，但优化收益仍需验证

本轮最终八组均通过 FP32、每轮更新前概率校验、64 轮及 actor/critic 各 256 个真实 AdamW 步验收。原 loader 边界错误产生的旧尝试被拒绝并归档，没有混入结果。没有理由将当前弱收益直接归咎于已修复的 BF16 概率不一致或把旧错误轨迹当作当前训练。

进一步读取八组原 log_history：

- 每组全程平均 policy approxKL 约 2.25e-6–4.25e-6。
- 平均 policy clip fraction 约 0.0023%–0.0090%，说明 ratio clip 很少触发，当前没有“被 clip 截断而动不了”的证据。
- 各组前八轮与后八轮训练 batch 的平均 Reward 没有呈现一致上升；这些 batch 的 prompt/采样回答不同，不能当作固定开发集上 Reward 没有改善的证明。
- 部分组 value loss 下降，但不同 Reward 的绝对分数和尺度差异很大，不能跨模型比较原始 value loss，也不能因 loss 非零就断言 critic 是主因。

approxKL 比较当前与 rollout 旧策略的局部更新，最终序列 KL MC 比较策略与参考 SFT，二者不是同一指标。小 approxKL 本身不能证明训练不够；当前证据支持检查“是否有效提高固定开发集 Reward”，尚不支持直接增加学习率或延长 episodes。

在相同评价生成协议下，PRISM 与 Empirical 回答逐字相同的比例为：2048 seed11/23 为 60.0%/69.4%，4096 为 59.4%/74.4%。这表明现有输出中有大量方法重合。共同生成 seed 的随机数耦合会影响相同比例，它不等于两个策略分布相等，也不证明二者都与 SFT 相同。

## Reward 与 Judge 的证据边界

八个 Reward 的正则化 BT 训练目标都数值收敛。但 PRISM 拟合的是集中采样分布，Empirical 拟合的是近均匀分布；PRISM 较低的训练 loss 不能作为泛化更好的证据。已验收训练报告尚未给出足以对两方法作统一比较的、按 prompt 隔离的 V2 独立开发集准确率/logloss。V1 的弱泛化结果也不能直接当作 V2 测量。

本轮训练和主评价使用 Sol high，交叉使用 Luna medium。比起此前单一较弱 Judge，它提供了更明确的模型偏好观测，但并不提供人类真值；同模型训练/主评可能共享偏好偏差。Luna 与 Sol 的逐顺序一致率 74.5%–92.0%，12 项同题差值区间均包含 0。当前主评是 Sol，不能将本轮结果直接归因于旧 Luna 主评的问题。

本轮也没有证明发生 Reward hacking。文献展示了代理 Reward 优化过强可能损害真实质量，因此在 Reward 泛化未明确前，盲目加大 PPO 强度不是可靠处理办法：[Gao 等，ICML 2023](https://proceedings.mlr.press/v202/gao23h.html)。成熟 RLHF 的关键链条是 Reward 对偏好的预测及其在策略优化中的有效性，而不只训练目标收敛：[Stiennon 等，NeurIPS 2020](https://arxiv.org/abs/2009.01325)。

## V3 的建议顺序（未执行）

1. 先建立所有方法共用、按 prompt 隔离的 Reward 开发验证：ranking accuracy、BT logloss、校准及不同来源/长度上的表现。保留冻结 backbone＋线性头，不擅自改成 Reward LoRA。先确定更多预算或不同采样是否确实改善与决策相关的 Reward 预测。
2. 对固定 V2 Reward 验证 PPO 的优化响应：用固定开发 prompt 比较训练前后 Reward/参考 KL、核对优势与 critic 拟合，再考虑奖励中心化、尺度、学习率或时长的小控制试验。Reward 改进和 PPO 更新应分开识别，不以最终测试集挑超参数。
3. 再比较采样协议：保留当前 PRISM 有放回作为清楚的基准；不放回、统一混合或覆盖约束分别作为显式新方案，控制相同标签费用与其余设置。若用人类固定偏好池，重复标签缓存不算新的独立观察，原 i.i.d. 界不能直接沿用。
4. 在端到端正收益更清楚后增加训练 seed、独立评价 prompts；保留 nested-prefix 的相关性，不把跨预算当独立重复。不能把单个 seed 的小优势或两个平均值的细小差别当结论。

对 PRISM 最重要的下一步证据是：在共同、独立的验证目标下，所选比较信息先改善 Reward，再改善同等优化预算下的策略。当前两个环节之间的传递尚未被本轮结果证实。
